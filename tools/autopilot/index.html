Autopilot Import & Check

  1. Upload a hardware hash CSV. Rows with a bad hash, a missing serial, or a duplicate are flagged and skipped.
  2. Tag everything at once or row by row.
  3. Import. Status refreshes on its own for a few minutes; failures show the reason and what to do about it.
  4. Readiness Check scores any serial: registered (30), profile assigned (35), group tag (15), recent check-in (10), not already enrolled (10).
