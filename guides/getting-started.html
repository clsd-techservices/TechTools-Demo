Getting Started

Free, browser-based Intune tools. Nothing to install: every tool is a web page that runs in the browser, and nothing is sent to anyone except Microsoft (when you connect your tenant) and the AI provider you choose.

What’s in the kit

  • Autopilot Import & Check: validate hash CSVs, tag and import, score device readiness
  • Remediation Generator: plain English to detection + remediation scripts, push to Intune
  • Win32 App Builder: MSI/EXE to scripts, Intune settings, and .intunewin packager
  • Kit Setup: your district name, colors, logo, tenant, and AI provider

Three ways to run it

  1. Double-click index.html. Offline mode: CSV checks, script generation, and packaging all work. No sign-in.
  2. Demo mode. Click Try with sample data in any tool (or add ?demo=1) to see it work against a simulated tenant.
  3. Connected. Host the folder and add an app registration to import and push straight to Intune.

1 · Make it yours

Open setup.html. Fill in your district, pick school colors, add a logo, then Download config and replace kit-config.js in this folder. Re-open setup any time and use Load an existing kit-config.js to edit.

2 · Host it (needed for sign-in)

Microsoft sign-in needs the kit served over https or from http://localhost. Quickest test on your own PC:

cd C:\path\to\tech-tools-kit
python -m http.server 8080
# then open http://localhost:8080

For a team, copy the folder to any web server (IIS, nginx, Apache). It’s static files only: no database, no server code.

3 · App registration (optional)

  1. Entra admin center → App registrations → New registration, single tenant.
  2. Redirect URI type Single-page application: https://your-host/your-kit/redirect.html
  3. API permissions → Microsoft Graph → Delegated:
    DeviceManagementServiceConfig.ReadWrite.All, DeviceManagementManagedDevices.Read.All, DeviceManagementConfiguration.ReadWrite.All, Group.Read.All
  4. Grant admin consent, then paste the client and tenant IDs into Kit Setup.

No client secret. Everyone signs in as themselves and can only do what their Intune role allows.

4 · AI provider

Pick Anthropic, OpenAI, Groq, or Google Gemini (Groq and Gemini have free tiers). Each person is asked for a key the first time they use an AI feature; it’s saved only in their browser and sent only to that provider. You can also add a fallback provider.

Good to know

  • Keys in kit-config.js are readable by anyone who can open the file. Keep them in the browser for hosted kits, and set a spend limit on every key.
  • AI-written scripts are a first draft. Read them and test on a lab device before deploying.
