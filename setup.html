How to create the app registration (about 5 minutes)
  1. Open the Microsoft Entra admin center → App registrations → New registration. Name it something like {{portalName}} Kit, single tenant.
  2. Under Redirect URI, choose Single-page application (SPA) and enter the kit's sign-in page:
  3. Copy the Application (client) ID and Directory (tenant) ID from the Overview page into the boxes above.
  4. API permissions → Add → Microsoft Graph → Delegated: DeviceManagementServiceConfig.ReadWrite.All and DeviceManagementManagedDevices.Read.All (Autopilot), DeviceManagementConfiguration.ReadWrite.All and Group.Read.All (Remediations).
  5. Click Grant admin consent. No client secret is needed: everyone signs in as themselves and only gets what their Intune role allows.
